All notable changes to the OpenModder skill.

## 0.1.0

- Initial release.
- `skills/openmodder/SKILL.md`: the eleven-stage loop (intake → recon → route → lab → source → slice →
  assets → verify → showcase → package → field note) with hard rules and an optional-toolkit table.
- References: `recon`, `engines`, `reverse-engineering`, `verification`, `assets`, `publish-and-notes`,
  `safety`.
- Documentation: install methods (global, project, config directory, HTTP catalog), the workflow and its
  artifacts, the optional toolkit and its replacements.
